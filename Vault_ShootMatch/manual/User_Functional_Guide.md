# SHOOTMATCH — Hướng dẫn Chức năng (Dành cho User)

Tài liệu ngắn gọn về luồng hoạt động của người dùng.

## 1. Khách hàng (Role 1)
1. **Tìm kiếm**: Lọc thợ qua màn hình Discovery.
2. **Kết nối**: 
    - Quẹt Phải: Gửi tín hiệu thích.
    - Match: Xảy ra khi thợ ảnh cũng thích bạn.
3. **Đặt lịch**: Chọn gói dịch vụ -> Chờ thợ xác nhận -> Chat thảo luận.
4. **Kết thúc**: Đánh giá thợ sau khi chụp xong.

## 2. Nhiếp ảnh gia (Role 2)
1. **Xây dựng hồ sơ**: Cập nhật Portfolio và Service Packages.
2. **Duyệt lịch**: Nhận yêu cầu từ khách -> Chấp nhận/Từ chối.
3. **Làm việc**: Chat với khách -> Thực hiện buổi chụp -> Đánh dấu hoàn thành.
