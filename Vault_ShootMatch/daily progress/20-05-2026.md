### 2. Nâng cấp API Backend (REST & Logic Xử Lý)
- **`CustomersController.cs` (Chuyên biệt cho Khách hàng):**
  - REST API `POST /api/customers/profile`: Cập nhật logic upsert thông minh. Khi nhận yêu cầu cập nhật, backend sẽ tự động merge/fallback về dữ liệu cũ nếu trường đó được gửi lên trống/null để tránh ghi đè làm mất thông tin cũ.
  - Triển khai **6 endpoint upload ảnh chuyên dụng** hỗ trợ `multipart/form-data`:
    - `POST /api/customers/profile/avatar/upload`
    - `POST /api/customers/profile/cover/upload`
    - `POST /api/customers/profile/highlight-1/upload`
    - `POST /api/customers/profile/highlight-2/upload`
    - `POST /api/customers/profile/highlight-3/upload`
    - `POST /api/customers/profile/roll-preview/upload`
  - Các endpoint đều validate định dạng ảnh nghiêm ngặt (chỉ nhận JPEG, PNG, WebP, HEIC), kết xuất tên file an toàn theo định dạng `customers/{kind}/{customerId}/{guid}{ext}` và đẩy lên Supabase Storage/LocalDisk trả về Public URL trực tiếp.
- **`PhotographersController.cs`:**
  - Thêm endpoint `PATCH /api/photographers/availability` để mobile cập nhật nhanh trạng thái rảnh/bận.
  - Sửa logic endpoint `POST /api/photographers/verify` để giữ nguyên các thông tin thực tế của photographer (`NationalId`, `PersonalAddress`, các file tài liệu xác minh) khi thiết lập trạng thái `Pending`.
